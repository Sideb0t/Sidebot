# SideBot

One-line local install on iPhone (Open Minis):

```sh
wget -qO- https://raw.githubusercontent.com/Sideb0t/Sidebot/main/install.sh | sh
```

Open in Safari after install:

```
http://127.0.0.1:8080/sidebot.html
```

Sign and install an IPA directly from terminal:

```sh
/root/sidebot-local/start.sh --ipa /path/to/app.ipa
```
